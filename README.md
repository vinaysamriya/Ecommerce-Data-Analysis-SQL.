# E-commerce Data Analysis Project 🛒📊

## Project Overview
This project demonstrates a complete Data Analytics workflow using SQL. I have designed and analyzed a normalized relational database for an E-commerce platform.

## Key Highlights
* **Database Design:** Created a normalized schema with 4 tables (`customers`, `products`, `orders`, `order_items`) using primary and foreign keys.
* **Data Engineering:** Inserted and structured realistic e-commerce datasets.
* **Data Analysis:** Solved 10 real-world business problems using complex SQL queries.
* **Skills Used:** `SELECT`, `WHERE`, aggregations (`SUM`, `COUNT`), `GROUP BY`, `ORDER BY`, and `INNER JOIN`.

## File Description
* `ecommerce_project.sql`: Contains the complete SQL script for creating tables, inserting data, and the 10 data analysis queries.
